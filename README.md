# Monumental Cafe Menu

This is a simple static webpage displaying the menu of **Monumental Cafe**, featuring a selection of coffee and desserts with their respective prices. The page is built using HTML and styled with CSS to provide an appealing visual design.

## Features

- **Coffee Menu**: A list of various coffee flavors and their prices.
- **Dessert Menu**: A list of popular desserts with prices.
- **Responsive Layout**: The webpage is designed to be responsive, ensuring a good display on various devices.
- **Visually Appealing**: A background image of coffee beans and an attractive layout with well-organized content and styled elements.

## Technologies Used

- **HTML**: For structuring the content of the page.
- **CSS**: For styling the page to give it an attractive and professional look.

### Styling Details:

- **Background Image**: The body background is styled with a coffee beans image to enhance the theme of the cafe.
- **Menu Container**: The menu is displayed in a centered container with a background color of burlywood and proper padding for a neat presentation.
- **Typography**: The text uses the "sans-serif" font family for general content and "Impact" for headings, making the cafe name and section titles stand out.
- **Item Layout**: Each coffee and dessert item is displayed with the name on the left and the price on the right. The items are listed with a clean and minimalist design, emphasizing readability.
- **Interactive Links**: The links are styled to change color on hover and when clicked, using a brown color that complements the cafe theme.
